# 🍅 ToDo Notificator (Pomodoro ToDo)

Мобильное приложение для управления задачами, сочетающее в себе планировщик дел, таймер концентрации по методу Помодоро и элементы игровой мотивации (геймификации). Приложение разработано на базе фреймворка **Flutter** и языка **Dart** с нативной интеграцией Android-сервисов на **Kotlin**.

---

## 🚀 Основные возможности

### 📋 Управление задачами (Task Management)
* **Полноценный планировщик**: Создание, редактирование, завершение и удаление задач.
* **Чек-листы**: Декомпозиция больших задач на мелкие подзадачи с отслеживанием прогресса.
* **Категории**: Группировка дел с цветовой кодировкой для удобной визуальной фильтрации.
* **Заметки**: Форматированные описания к задачам (жирный шрифт, курсив, гиперссылки).
* **Сгоревшие задачи (Кладбище)**: Архив проваленных задач с возможностью их окончательного удаления или восстановления в основной список.

### ⏱️ Таймер Помодоро (Pomodoro Timer)
* **Два режима работы**: Свободная сессия фокусировки или привязка таймера к конкретной задаче.
* **Гибкая настройка**: Автоматическое переключение между фазами фокуса, короткого отдыха и длительного перерыва.
* **Звуковое сопровождение**: Аудиоэффекты запуска, паузы и окончания сессий.
* **Строгий режим (Strict Mode)**: Повышает дисциплину — при сворачивании приложения во время сессии более чем на 10 секунд задача считается проваленной («сгорает»), а пользователь получает штраф.

### 🎮 Геймификация и Мотивация (Gamification)
* **Очки опыта (XP)**: Начисление опыта за полезные действия (создание и выполнение задач, закрытие пунктов чек-листа, успешные сессии таймера).
* **Уровни**: Динамический расчет уровня профиля пользователя по прогрессивной формуле.
* **Серии активности (Streaks)**: Отслеживание количества дней подряд, в которые пользователь проявлял продуктивность.
* **Система достижений (Achievements)**: Награды с получением уникальных ачивок за долгосрочные успехи.
* **XP-Тосты**: Анимированные всплывающие уведомления о получении или потере опыта в реальном времени.

### 📱 Системные функции
* **Нативная Android-интеграция**: `Foreground Service` на Kotlin обеспечивает непрерывную фоновую работу таймера и выводит постоянное уведомление в статус-баре.
* **Локальное хранение**: Автономная работа без интернета на базе реляционной СУБД SQLite (пакет `sqflite`).
* **Экспорт и импорт данных**: Резервное копирование всех данных пользователя в файл JSON с возможностью быстрого восстановления.
* **Локализация**: Полная поддержка русского и английского языков интерфейса.

## 🛠️ Технологический стек

* **Core**: Flutter (Dart), Material Design 3.
* **База данных**: SQLite (через `sqflite` и миграции схемы БД до 7-й версии).
* **Нативный слой Android**: Kotlin, Android Foreground Service, MethodChannel, BroadcastReceivers.
* **Уведомления**: `flutter_local_notifications` + `timezone`.
* **Звук**: `audioplayers`.
* **Тестирование**: Модульные и UI-тесты на базе `flutter_test` и `mocktail`.

## 📐 Архитектура проекта

Приложение спроектировано по архитектурному паттерну **MVVM (Model-View-ViewModel)**. Доступ к зависимостям организован через собственный Service Locator на основе `InheritedWidget` (`AppScope`), что избавляет проект от лишних сторонних DI-библиотек.

### Структура каталогов (`lib/`):
* `app/` — глобальное состояние приложения, жизненный цикл, темы оформления, навигация и логика таймера (`timer_controller.dart`).
* `data/` — локальная база данных, модели данных, контракты репозиториев и их локальные реализации.
* `l10n/` — файлы локализации интерфейса (`.arb`).
* `screens/` — экраны пользовательского интерфейса (экраны входа, настроек, списков задач, таймера, профиля и кладбища).
* `services/` — вспомогательные сервисы: игровая логика геймификации, воспроизведение звуков, пуш-уведомления.
* `ui/` — дизайн-система: общие виджеты, стили цветов, кастомные текстовые поля и анимированные тосты.
* `view_models/` — классы хранения и управления состоянием экранов (ViewModels).

## ⚡ Быстрый старт

### Требования
* Flutter SDK (версии `^3.11.1`)
* Android SDK (для запуска Android-приложения с Foreground-сервисом)

### Запуск приложения
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/kirill010106/todonotificator_androidclient.git
   cd todonotificator_androidclient
   ```
2. Установите зависимости:
   ```bash
   flutter pub get
   ```
3. Запустите проект:
   ```bash
   flutter run
   ```

### Запуск тестов
Для верификации бизнес-логики и виджетов выполните команду:
```bash
flutter test
```
